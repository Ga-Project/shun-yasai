# 旬やさい相場ナビ

いま野菜が **平年に比べて安いのか高いのか** を、公的統計だけを使って即答するサイトです。

「今日のキャベツ、高い気がするけど本当に高いの？」に数字で答えます。値段そのものより
**平年（例年の同じ時期）と比べてどうか** を主役にしているので、季節による値上がりと、
不作や天候による本当の高値を切り分けられます。

## できること

- 調査対象 10 品目の小売価格と、平年比（平年＝1.00）を一覧で比較できる
- 安い順に並ぶので「いま買い時の野菜」がひと目で分かる
- 品目ごとに、週ごとの値動きと、例年その品目が安くなる月を確認できる
- 月から引いて「この月に安い野菜」を調べられる
- 直売所に出荷する人向けに、店舗別の価格メモを端末内に記録できる（おまけ機能）

## データについて

- 出典: 農林水産省「食品価格動向調査（野菜）」
- 対象: キャベツ / ねぎ / レタス / ばれいしょ / たまねぎ / きゅうり / トマト / にんじん / はくさい / だいこん
- 更新: 調査は原則として毎週（火曜公表）。本サイトは取り込み時点のデータを表示します
- 平年比: 調査が公表している値をそのまま使っています（独自の推計ではありません）

価格は調査時点の小売実態の目安で、特売価格を含みません。実際の店頭価格を保証するものでは
ありません。また調査は品目ごとに時期が決まっているため、時期外の品目は最新の数字がありません
（その場合は「いまは調査時期外」と表示します）。

## データを更新する

```bash
python3 scripts/refresh_data.py
```

公開元の Excel を取得して `data/prices.json` を作り直します。Python 標準ライブラリだけで動きます。
ビルド時には実行しません（生成済みの JSON だけを読むので、ビルドが外部サイトの状態に左右されません）。

列の並びや品目名が公開元で変わった場合はスクリプトが停止します。黙って別品目の数字を
取り込まないようにするためです。

## 開発
